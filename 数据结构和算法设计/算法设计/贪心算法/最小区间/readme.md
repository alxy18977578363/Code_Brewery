# LeetCode 632. 最小区间

## 题目描述

你有 `k` 个非递减排列的整数列表。你需要找到一个**最小区间**，使得这 `k` 个列表中的每个列表至少有一个数包含在这个区间内。

我们定义区间 `[a,b]` 比 `[c,d]` 小，当且仅当：
- `b - a < d - c`，或者
- `b - a == d - c` 且 `a < c`

## 示例

**示例 1：**
输入：nums = [[4,10,15,24,26], [0,9,12,20], [5,18,22,30]]
输出：[20,24]
解释：
列表 1: [4, 10, 15, 24, 26] → 24 在 [20,24] 中
列表 2: [0, 9, 12, 20] → 20 在 [20,24] 中
列表 3: [5, 18, 22, 30] → 22 在 [20,24] 中


**示例 2：**
输入：nums = [[1,2,3],[1,2,3],[1,2,3]]
输出：[1,1]

## 数据范围

- `nums.length == k`
- `1 ≤ k ≤ 3500`
- `1 ≤ nums[i].length ≤ 50`
- `-10^5 ≤ nums[i][j] ≤ 10^5`
- `nums[i]` 按非递减顺序排列

## 解题思路

### 方法一：最小堆 + 指针

1. **初始化**：
   - 使用最小堆维护当前所有列表的最小元素
   - 使用指针数组记录每个列表当前的位置
   - 维护当前的最大值

2. **算法过程**：
   - 每次从堆中取出最小值，计算当前区间
   - 移动取出元素所在列表的指针
   - 将新元素加入堆，并更新最大值
   - 直到某个列表被遍历完

3. **复杂度分析**：
   - 时间复杂度：O(nlogk)，n是所有元素的总数
   - 空间复杂度：O(k)
