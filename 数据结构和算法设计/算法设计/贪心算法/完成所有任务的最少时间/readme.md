## 完成所有任务的最少时间
你有一台电脑，可以同时运行无数个任务。给你一个二维整数数组 `tasks`，其中 `tasks[i] = [start_i, end_i, duration_i]` 表示第 `i` 个任务需要在闭区间 `[start_i, end_i]` 内运行 `duration_i` 个时间单位（不需要连续）。

当电脑在运行某个任务时，它可以在时间段 `[start_i, end_i]` 内的任意时间单位执行该任务，包括边界 `start_i` 和 `end_i`。但是，同一时间单位不能同时运行多个任务。

请你返回完成所有任务所需的最少时间单位数。

## 示例

### 示例 1
**输入：**
```
tasks = [[2,3,1],[4,5,1],[1,5,2]]
```
**输出：**
```
2
```
**解释：**
- 第一个任务在时间单位 2 运行。
- 第二个任务在时间单位 5 运行。
- 第三个任务在时间单位 1 和 3 运行（或时间单位 1 和 4）。
总共需要 2 个时间单位，因此返回 2。

### 示例 2
**输入：**
```
tasks = [[1,3,2],[2,5,3],[5,6,2]]
```
**输出：**
```
4
```
**解释：**
- 第一个任务在时间单位 2 和 3 运行。
- 第二个任务在时间单位 2、4 和 5 运行。
- 第三个任务在时间单位 5 和 6 运行。
总共需要 4 个时间单位，因此返回 4。
