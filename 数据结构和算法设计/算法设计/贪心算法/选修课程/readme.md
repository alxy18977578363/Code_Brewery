# 选修课程

## 题目描述

你需要选择一些课程进行学习。给定一个包含 `n` 门课程的数组 `courses`，其中 `courses[i] = [durationi, lastDayi]` 表示第 `i` 门课程将持续 `durationi` 天完成，并且必须在 `lastDayi` 之前完成（包括 `lastDayi`）。

你的任务是在不违反任何课程截止时间的前提下，计算出你最多可以选修多少门课程。

## 示例

### 示例 1
**输入:**  
`courses = [[100, 200], [200, 1300], [1000, 1250], [2000, 3200]]`  
**输出:**  
`3`  
**解释:**  
你可以选修：
1. 第一门课程，耗时 100 天，在第 100 天完成（未超过截止时间 200 天）。
2. 第三门课程，耗时 1000 天，在第 1100 天完成（未超过截止时间 1250 天）。
3. 第二门课程，耗时 200 天，在第 1300 天完成（未超过截止时间 1300 天）。
第四门课程无法选修，因为即使你从第 1300 天开始学习，也会在第 3300 天完成，超过截止时间 3200 天。

### 示例 2
**输入:**  
`courses = [[1, 2]]`  
**输出:**  
`1`  
**解释:**  
你可以选修唯一的一门课程。

### 示例 3
**输入:**  
`courses = [[3, 2], [4, 3]]`  
**输出:**  
`0`  
**解释:**  
没有任何一门课程可以在截止时间前完成。

## 提示
- `1 <= courses.length <= 10^4`
- `1 <= durationi, lastDayi <= 10^4`

## 解题思路
1. **排序处理**：首先按照课程的截止时间 `lastDay` 进行升序排序。
2. **贪心选择**：使用优先队列（最大堆）动态维护已选课程的持续时间。每次遇到新课程时，尝试将其加入已选课程，如果总时间超过当前课程的截止时间，则弹出持续时间最长的课程。
3. **计算最优解**：最终优先队列中的课程数量即为最多可以选修的课程数。
