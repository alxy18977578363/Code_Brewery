# 279. 完全平方数
## **题目描述**  

给你一个整数 `n`，返回和为 `n` 的**完全平方数**的最少数量。  

**完全平方数**是指其值等于某个整数的平方的数（例如，`1 = 1×1`，`4 = 2×2`，`9 = 3×3`，`16 = 4×4`）。  

**示例 1：**  
输入：`n = 12`  
输出：`3`  
解释：`12 = 4 + 4 + 4`（最少需要 3 个完全平方数）  

**示例 2：**  
输入：`n = 13`  
输出：`2`  
解释：`13 = 4 + 9`（最少需要 2 个完全平方数）  

**提示：**  
- `1 <= n <= 10^4`  

## **题目理解**  
- 我们需要将给定的整数 `n` 分解成若干个完全平方数的和，并且要求这些平方数的**数量最少**。  
- 例如：  
  - `12` 可以分解为 `9 + 1 + 1 + 1`（4 个），但最优解是 `4 + 4 + 4`（3 个）。  
  - `13` 可以分解为 `9 + 4`（2 个），比 `4 + 4 + 4 + 1`（4 个）更优。
