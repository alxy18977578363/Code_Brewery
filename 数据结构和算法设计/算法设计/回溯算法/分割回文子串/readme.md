# 131. 分割回文子串
## **题目描述**  

给你一个字符串 `s`，要求将 `s` 分割成若干子串，使得每个子串都是**回文串**。返回所有可能的分割方案。  

**示例 1：**  
输入：`s = "aab"`  
输出：`[["a","a","b"], ["aa","b"]]`  

**示例 2：**  
输入：`s = "a"`  
输出：`[["a"]]`  

**提示：**  
- `1 <= s.length <= 16`  
- `s` 仅由小写英文字母组成  
 

## **示例解释**  
- **示例 1 (`"aab"`)**：  
  - 有效分割方式 1：`"a"`, `"a"`, `"b"`（每个子串都是回文）。  
  - 有效分割方式 2：`"aa"`, `"b"`（`"aa"` 是回文，`"b"` 也是回文）。  
  - 无效分割方式（如 `"a"`, `"ab"`，因为 `"ab"` 不是回文）。  

- **示例 2 (`"a"`)**：  
  - 唯一可能的分割方式：`["a"]`（因为字符串只有一个字符）。
