# **题目名称**  
## **24点游戏**  

### **题目描述**  
给定4个整数 `cards`，每个整数的取值范围是 `[1, 9]`。你的任务是判断是否可以通过加（`+`）、减（`-`）、乘（`*`）、除（`/`）运算，以及括号 `()` 的组合，使得最终的计算结果为 `24`。  

**注意：**  
1. 除法运算 `/` 是**实数除法**，而不是整数除法。例如，`4 / (1 - 2/3) = 12` 是一个合法的运算。  
2. 每个数字必须**使用且仅使用一次**，不能重复使用，也不能省略不用。  
3. 不能将数字**拼接**使用（例如，`12` 不能由 `1` 和 `2` 拼接而成）。  

### **示例**  
**示例 1：**  
输入：`cards = [4, 1, 8, 7]`  
输出：`true`  
解释：  
`8 / (1 - (7 / 4)) = 24`  

**示例 2：**  
输入：`cards = [1, 2, 1, 2]`  
输出：`false`  
解释：无法通过这些数字和运算得到 24。  

### **约束条件**  
- `cards.length == 4`  
- `1 <= cards[i] <= 9`
