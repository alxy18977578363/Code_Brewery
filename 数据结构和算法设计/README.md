1. 今天通过期中大作业学习了排序算法，分治算法和动态规划
  - 随机划分线性选择让我印象深刻，和第一问的排序算法类似，主要基于**快速排序算法**
  - 该算法要分为partition和quickSort两部分函数完成，quickSort若是递归函数，那就递归本身；若是循环解决，那就是循环partition
  - 在partition中，随机选择一个数为基准，和arr[high]交换位置，l = low,r = high - 1。要求是l<=r,才能保证最后l的位置涉足大于pivot的数，从而交换的时候才不会出问题。
  - 而且，l<=r下，能解决边界问题，比如3，2，1，4，7，7为基准,如果用l<r的话，那么最后一步是4与7交换，显然不合题意，但l<=r可使得7与7交换，处理了边际。
  - 或者单开一个数组，小的放前面，大的放后面。
