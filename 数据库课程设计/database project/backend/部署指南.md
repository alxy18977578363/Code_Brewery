## 🔧 环境准备

### 1. 安装Java (JDK 11+)

**检查是否已安装：**
```bash
java -version
```

**如果未安装，请下载安装：**
- 推荐：[Eclipse Temurin](https://adoptium.net/)
- 选择：Java 11 LTS 或 Java 17 LTS

**验证安装：**
```bash
java -version
javac -version
```

### 2. 安装MySQL

确保MySQL服务正在运行：
```bash
# Windows服务管理
services.msc

# 或使用命令行
net start MySQL80
```

### 3. 安装Gradle（可选）

如果想要使用本地Gradle：
- 下载：https://gradle.org/install/
- 解压并配置PATH环境变量

**或者直接使用项目自带的Gradle Wrapper（推荐）**

## 🎯 初始化Gradle

### 方法1：使用本地Gradle生成Wrapper（推荐）

```bash
cd backend
gradle wrapper --gradle-version 8.5
```

### 方法2：下载预编译的Wrapper

如果没有安装Gradle，从这里下载gradle-wrapper.jar：
https://github.com/gradle/gradle/raw/master/gradle/wrapper/gradle-wrapper.jar

将下载的文件放到：
```
backend/gradle/wrapper/gradle-wrapper.jar
```

### 方法3：运行setup脚本

```bash
cd backend
setup-gradle.bat
```

## 💾 配置数据库

### 1. 创建数据库

连接到MySQL并执行：
```sql
CREATE DATABASE IF NOT EXISTS ocean_database 
    CHARACTER SET utf8mb4 
    COLLATE utf8mb4_unicode_ci;
```

### 2. 导入数据库结构

```bash
# 如果有demo.sql文件
mysql -u root -p ocean_database < ../demo.sql
```

### 3. 配置数据库连接

编辑 `backend/config/database.properties`：

```properties
db.url=jdbc:mysql://localhost:3306/ocean_database?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true
db.user=root
db.password=你的密码
```

### 4. 测试连接

```bash
# 使用MySQL命令行测试
mysql -u root -p ocean_database
```


## ❓ 常见问题

### Q1: 端口3000被占用

**解决方案：**
编辑 `src/main/java/com/ocean/database/Application.java`，修改端口：
```java
int port = 3001; // 改为其他端口
```

### Q2: 数据库连接失败

**检查清单：**
- [ ] MySQL服务是否启动
- [ ] 数据库名称是否正确
- [ ] 用户名和密码是否正确
- [ ] 配置文件路径是否正确

**解决方案：**
```bash
# 检查MySQL服务
net start | findstr MySQL

# 测试连接
mysql -u root -p -e "SHOW DATABASES;"
```

### Q3: Gradle下载慢

**解决方案：**
使用国内镜像，编辑 `gradle/wrapper/gradle-wrapper.properties`：
```properties
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.5-bin.zip
```

或者在 `build.gradle` 中添加：
```gradle
repositories {
    maven { url 'https://maven.aliyun.com/repository/public/' }
    maven { url 'https://maven.aliyun.com/repository/central/' }
    mavenCentral()
}
```

### Q4: 找不到gradlew.bat

**解决方案：**
运行 `setup-gradle.bat` 生成Gradle Wrapper

### Q5: 前端无法连接后端（CORS错误）

**检查：**
- 后端服务是否运行在3000端口
- 前端API配置是否正确

**前端配置：**
编辑 `frontend/src/api/index.js`：
```javascript
baseURL: 'http://localhost:3000/api'
```

### Q6: Java版本不匹配

**解决方案：**
```bash
# 检查Java版本
java -version

# 如果版本过低，下载安装Java 11+
# https://adoptium.net/
```

## 📦 部署到生产环境

### 1. 构建Fat JAR

```bash
gradlew.bat jar
```

生成的JAR位于：`build/libs/ocean-database-backend-1.0.0.jar`

### 2. 运行JAR

```bash
java -jar build/libs/ocean-database-backend-1.0.0.jar
```

### 3. 后台运行（Windows）

创建Windows服务或使用任务计划程序

### 4. 使用配置文件

确保 `config/database.properties` 与JAR在同一目录级别

## 🔍 日志和调试

### 查看日志级别

默认使用SLF4J Simple Logger，日志输出到控制台

### 修改日志级别

创建 `src/main/resources/simplelogger.properties`：
```properties
org.slf4j.simpleLogger.defaultLogLevel=debug
org.slf4j.simpleLogger.log.com.ocean.database=debug
```
