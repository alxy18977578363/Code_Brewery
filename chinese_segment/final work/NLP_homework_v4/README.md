# 智能化文献综述生成与分析系统 (NLP Agent)

基于大语言模型（LLM）与多智能体（Multi-Agent）架构的自动化文献分析平台。本系统旨在解决科研人员在文献调研阶段面临的**检索难、阅读慢、总结散、易幻觉**四大痛点。只需输入一个模糊的研究方向，系统即可全自动完成“**交互选题 → 跨源检索 → 全文精读 → 结构化抽取 → 主题聚类 → 多智能体深度写作与纠错**”的全流程，并最终生成具有极高学术参考价值的图文并茂的综述报告与学术海报。

---

## 🚀 一、 操作指南与环境配置

### 1. 环境准备
本项目基于 Python 3.9+ 编写。推荐使用 Conda 隔离环境：
```bash
# 1. 创建并激活虚拟环境
conda create -n nlp_agent python=3.9 -y
conda activate nlp_agent

# 2. 安装核心依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. API 密钥配置 (核心提速点)
复制配置模板文件：
```bash
cp .env.example .env
```
在 `.env` 中填入您的 API Key：
```dotenv
# 支持单 Key 或 多 Key 轮询（用英文逗号分隔，强烈推荐多 Key 部署以解锁极速并发）
DEEPSEEK_API_KEY=sk-key1,sk-key2,sk-key3
DEEPSEEK_MODEL=deepseek-chat
```
*提示：如不配置 Key，系统依然可运行，但抽取和写作功能会自动降级为本地纯规则（正则+词典）模式。*

### 3. 一键启动
```bash
python app.py
```
控制台输出 `* Running on http://127.0.0.1:5000` 后，打开浏览器访问该地址即可进入控制台。

## 🎨 二、 平台功能全景图 (按键指南,报告核心素材)

本系统前端界面分为“**检索控制台**”、“**流水线监控**”和“**深度分析面板**”三大模块。以下为各核心按键与交互功能说明：

### 🔍 1. 检索控制台
- **`💬 选题助手` 按钮**：如果您仅有模糊的灵感（如“大模型 医疗”），点击此按钮唤出 **AI 选题导师**。通过多轮自然语言对话，导师会引导您明确具体场景与方法，并在对话末尾提供黄色的**一键填入**按钮，精准设定检索词。
- **主题与参数输入框**：支持全中文输入（系统会自动在底层翻译为英文检索 arXiv）。可调整 `起始/结束年份` 及检索 `最大篇数`。
- **`✨ 全局全文精读` 勾选框**：勾选后，系统将在检索完成后，自动并发爬取所有命中论文的 **HTML / PDF 全文**，提取其中隐藏极深的评测数据集、具体 Metric 精度、硬件消耗等深度指标。
- **`一键运行` 按钮**：触发 Pipeline 主干，开启自动翻译、检索、去重、排版、生成的无人值守流程。

### 📊 2. 数据可视化面板
- **流水线日志框**：实时回显系统底层的 Agent 思考过程与网络请求状态。
- **关键词词云与年份折线图**：对提取出的大规模语料进行可视化，直观感受技术热点与时间分布规律。
- **文献清单表**：
  - **`[Github ⭐]` 标签**：自动抓取并展示论文对应的开源代码库及其实时 Star 数。
  - **`📖 查阅详评` 按钮**：若开启了全文精读，点击可弹出 Agent 针对该单篇论文生成的结构化深度分析报告。

### 📝 3. 多智能体综述写作与优化区
- **综述草稿区**：展示基于检索文献生成的长文综述。所有论文均采用严谨的 `[n]` 学术角标引用。
- **`✨ 深度审核与优化` 按钮 (多级 Level)**：
  - **Level 1 (基础润色)**：仅对行文流畅度做轻量级修正。
  - **Level 2 (深度打假)**：启动 **Grounding Agent** 与 **Auditor Agent**，地毯式扫描文章中的事实错误、乱安名头（张冠李戴）等大模型“幻觉”，并强制重写修复。
  - **Level 3 (极限迭代)**：执行多轮找茬与重写对抗。
- **⚠ 引用核查警告框**：在初步生成时，系统若发现综述中将某方法错误归属于未提出该方法的论文，会亮起黄色警告框指出“张冠李戴”的幻觉片段。点击优化后，该警告会被自动消除。
- **🧬 算法演进图**：自动提炼所有文献的时间线，渲染为 Mermaid 时序图，并带有底层的自动时间错乱纠正器。
- **`生成学术海报` 按钮**：点击将整个项目的精华（核心摘要、关键图表、演进图、高频词）一键重排为响应式学术海报结构，可直接呼出浏览器 `Print` 存为高清 PDF。

## 🛠 三、 工程实现与底层优化 (报告核心素材)

本项目的核心工作量并不局限于前端页面的堆砌，而在于构建了一个具有极高**鲁棒性、并发性、容错性**的后端 Agent 架构。以下为系统核心技术方案（强烈建议在此基础上撰写大作业报告）：

### 1. 高吞吐：多 API Key 轮询与动态并发扩容 (Round-Robin Key Pool)
- **痛点**：深度精读和并发写作需要极高的 LLM 并发度，极易触发官方单账号的限流（429 Too Many Requests）和 TPM 上限。
- **工程实现**：系统在 `config.py` 中原生实现了基于 `itertools.cycle` 的 **API Key 代理池**。
- **效果**：系统会实时侦测环境中的 Key 数量，并动态调节 `ThreadPoolExecutor` 的线程上限（公式为：`max_workers = 5 * N`）。当填入 3 个 API Key 时，系统会将并行处理能力直接拉升至 15 线程并发。系统将所有请求按时间片均匀打散（Round-Robin）分发给不同的 Key，完美绕过各大平台的并发风控，在 1 分钟内即可完成数十篇论文的精读与数万字的综述写作。

### 2. 高质量检索：TF-IDF 相关性重排与降级爬虫
- **TF-IDF 语义加权**：传统的 API 检索常常存在“词面碰巧命中但主题毫不相干”的问题。系统实现了一套定制的重排序器（Reranker），利用局部 IDF（Inverse Document Frequency）对通用词（如 Network、Model）进行降权，对特异词（如 Chinese NER）进行加权，计算重要词覆盖率。低于阈值的离题论文会被硬性剔除，极大提升了源头数据的纯度。
- **多源防断路器机制**：在源码挖掘时，系统优先请求 PapersWithCode API，若遭遇反爬拦截，系统内置了直接请求 HuggingFace HTML 页面并通过正则表达式和 BeautifulSoup 强制刮取代码仓库链接的 Fallback 后备方案。

### 3. 多智能体协作架构 (Multi-Agent Workflows)
相比于单次调用 LLM 生成全文导致的长文本质量崩塌和逻辑混乱，本系统采用了工业级的 SOP（标准作业程序）拆解方案：
1. **Planner Agent (架构师)**：通览所有提取到的论文元数据与聚类簇，为最终综述生成严密的 JSON 大纲。
2. **Dynamic RAG Middleware (动态路由分配)**：将大纲中的各个小节分别映射到具体的聚类结果，为后续的撰写提供纯净、无干扰的小范围上下文。
3. **Parallel Writer Agents (并发主笔)**：每一个章节由一个独立的 LLM 实例负责并发撰写。
4. **Grounding Agent (打假巡视员)**：独创的“张冠李戴”探测器。利用 LLM 的语义理解能力核对每一处引用编号，若发现某句话中提到了一种方法，但这篇引用的论文其实并未提出它，Agent 会精准生成缺陷定位 JSON。
5. **Auditor Agent (审阅人) & Reviser Agent (主编)**：形成“对抗博弈网络”。Auditor 拿着真实文献和 Grounding Agent 发出的警报对草稿进行严厉批评，生成《缺陷报告》；Reviser 则根据这份报告对文本进行原样结构下的局部精细重写。两者的互相制约有效将模型的“幻觉率”降到了极低的水平。

### 4. 经济性与上下文优化 (Context & Token Optimization)
- **“接力棒式”缓存优化**：在多级优化环节，系统并非每次都粗暴地重新请求幻觉检测。前端在调用优化接口时，会将初次生成时产生的 `unsupported_claims`（缺陷列表）缓存并传回后端，后端在第 1 轮审核时完美复用该记录，直接省去了一整次极其昂贵的 LLM 全文巡查 Token 开销。
- **Mermaid 时间嗅探纠正引擎**：大语言模型常在绘制时序图时编造虚假年份。系统在后端截获了生成的 Mermaid 代码，采用正则引擎强制对比图表内的年份节点和真实学术数据的发布时间（甚至兼容 arXiv 2103.xxx 的单月级别排期逻辑），并在内存中自动订正图表，使得最终呈现的图表绝对吻合客观事实。
- **Flask 底层适配优化**：修复了在 Windows 开发环境下，由高并发多线程和 Werkzeug 文件监听器竞争造成的 `[WinError 10038]` 异常奔溃问题。通过禁用调试器中潜在的资源泄露行为，保障了长时间、高吞吐科研工作任务的绝对稳定。
