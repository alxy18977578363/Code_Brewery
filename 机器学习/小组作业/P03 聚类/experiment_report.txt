【性能评估指标】
 Method  Silhouette Score  Calinski-Harabasz Index  Davies-Bouldin Index
K-Means          0.339788              1605.906611              1.356367
 DBSCAN         -0.016092                44.402269              0.959761

指标解释:
  - Silhouette Score (轮廓系数): 范围[-1,1], 越接近1表示簇越紧密且分离
  - Calinski-Harabasz Index: 簇间方差与簇内方差比, 越大越好
  - Davies-Bouldin Index: 簇内外距离比的平均值, 越小越好

【算法对比分析】

K-Means:
  优点: ✓ 快速高效 ✓ 结果稳定 ✓ 易于理解
  缺点: ✗ 需预设K值 ✗ 只适合凸形簇 ✗ 对异常值敏感
  适用场景: 大规模数据、已知簇数、球形分布

DBSCAN:
  优点: ✓ 自动确定簇数 ✓ 发现任意形状 ✓ 识别噪声点
  缺点: ✗ 参数敏感 ✗ 密度不均时效果差 ✗ 高维效果下降
  适用场景: 未知簇数、不规则形状、含噪声数据
