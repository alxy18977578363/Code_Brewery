## 第一题
**误差反向传播描述不正确的是（ ）**  
**选项：**  
A. 误差反向传播算法是一种将输出层误差反向传播给隐藏层进行参数更新的方法  
B. 误差反向传播算法将误差从后向前传递，获得各层单元所产生误差，进而依据这个误差修正各单元参数  
C. 对前馈神经网络而言，误差反向传播算法可调整相邻层神经元之间的连接权重大小  
D. 在误差反向传播算法中，每个神经元单元可包含不可偏导的映射函数  

**分析：**
- A：正确。误差反向传播的核心思想是将输出层的误差反向传播到隐藏层，用于更新参数。  
- B：正确。这是误差反向传播的基本流程，误差从后向前传递，用于计算各层误差并修正参数。  
- C：正确。前馈神经网络的权重是通过反向传播算法调整的。  
- D：不正确。反向传播算法要求神经元单元的映射函数是可偏导的（即函数可微），因为需要通过链式法则计算梯度。不可偏导的函数会导致梯度无法传播。  

**答案：D**



## 第二题
**关于梯度下降和随机梯度下降的说明，描述正确的是（ ）**

**选项：**  
A. 在梯度下降和随机梯度下降中，为了最小化损失函数，通常使用循环迭代的方式不断更新模型参数  
B. 在每次迭代中，随机梯度下降需要计算训练集所有样本的误差和，用于更新模型参数  
C. 在每次迭代中，梯度下降使用所有数据或者部分训练数据，用于更新模型参数  
D. 在梯度下降和随机梯度下降中，需要最大化损失函数  

**分析：**
- A：正确。梯度下降和随机梯度下降都是通过迭代更新参数来最小化损失函数。  
- B：不正确。随机梯度下降（SGD）每次迭代仅使用一个样本或一个小批量样本计算误差，而不是全部样本。  
- C：不正确。梯度下降（Batch Gradient Descent）每次迭代使用所有数据计算梯度；随机梯度下降使用部分数据（如小批量）。选项描述混淆了二者。  
- D：不正确。梯度下降的目标是最小化损失函数，而非最大化。  

**答案：A**


## 第三题
**关于 sigmoid 激活函数，下列描述正确的是（ ）**  
**选项：**  
A. 它是凸函数，凸函数无法解决非凸问题  
B. 它可以有负值  
C. 它无法配合交叉熵损失函数使用  
D. 当输入值过大或国小时，梯度趋近于0，容易造成梯度消失的问题

**分析：**
- A：不正确。Sigmoid 函数是非凸函数（其输出曲线呈 S 形），但神经网络的损失函数通常是非凸的，这与能否解决非凸问题无直接关系。  
- B：不正确。Sigmoid 函数的输出范围是 (0,1)，不可能为负值。  
- C：不正确。Sigmoid 常与交叉熵损失函数配合使用（如二分类问题），因为可以避免梯度消失问题。  
- D：正确。



## 第四题
**题目描述：**  
**下面对前馈神经网络这种深度学习方法描述不正确的是（ ）。**  
**选项：**  
A. 是一种增强学习的方法  
B. 是一种提高学习的方法  
C. 实现了非线性映射  
D. 隐藏层数且大小对学习性能影响不大  

**答案与解析：**  
- **正确答案：A**  
  - **A错误**：前馈神经网络属于监督学习，与增强学习（Reinforcement Learning）无关。增强学习通过环境交互学习策略（如游戏AI）。  
  - **B干扰项**："提高学习"非标准术语，可能为笔误。  
  - **C正确**：通过激活函数（如ReLU）实现非线性映射。  
  - **D部分错误**：隐藏层数量和大小显著影响性能，但某些简单任务可能影响较小。  


### 第五题
**题目描述：**  
图5.19展示了长短时记忆网络的详细结构。以下描述正确的是（ ）。  
**选项：**  
A. 如果输入x为零向量，则 $h_i = h_{i-1}$  
B. 如果f非常小或者为0，则误差不会被反向传播到较早的时间节点  
C. f、i和o的输出是非负数  
D. f、i和o的输出可以被看作概率分布，其输出为非负数且和为1  

**答案与解析：**  
- **正确答案：C**  
  - **A部分正确**：若输入x为零向量，遗忘门f≈1（保留记忆），但需结合其他门控状态。  
  - **B正确**：遗忘门f接近0会阻断梯度传播（梯度消失），但题目要求单选。  
  - **C正确**：f（遗忘门）、i（输入门）、o（输出门）通过Sigmoid激活，输出∈(0,1)。  
  - **D错误**：三者独立计算，总和不为1（非概率分布）。
