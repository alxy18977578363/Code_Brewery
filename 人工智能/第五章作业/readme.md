## 题目2
**在强化学习中，以下两个步骤的迭代可学习得到最佳策略的是（    ）。**  
**选项**：  
A. 价值函数计算与动作－价值函数计算  
B. 动态规划与 Q-learning  
C. 贪心策略优化与 Q-learning  
D. 策略优化与策略评估  

**答案**：**D**  
**解析**：  
- **策略迭代（Policy Iteration）** 的核心步骤是：  
  1. **策略评估**：计算当前策略的价值函数。  
  2. **策略优化**：基于价值函数改进策略（如贪心策略）。  
 



## 题目3
**在强化学习中，以下机制的引入使得强化学习具备在利用与探索中寻求平衡的能力的是（    ）。**  
**选项**：  
A. ε-贪心策略  
B. 蒙特卡洛采样  
C. 动态规划  
D. 贝尔曼方程  

**答案**：**A**  
**解析**：  
- **ε-贪心策略**：以概率 ε 随机探索新动作，以概率 ε 选择当前最优动作（利用），直接解决了探索与利用的平衡问题。  
  

## 题目4
**与马尔可夫奖励过程相比，马尔可夫决策过程引入的新元素是（    ）。**  
**选项**：  
A. 反馈  
B. 动作  
C. 终止状态  
D. 概率转移矩阵  

**答案**：**B**  
**解析**：  
- **马尔可夫奖励过程（MRP）**：仅有状态、转移概率、奖励，无决策能力。  
- **马尔可夫决策过程（MDP）**：引入**动作（Action）**，使智能体能够主动选择行为，从而形成策略。  

## 题目5
**根据本章内容，“在状态 \(s\) 按照某个策略行动后在未来所获得回报值的期望”这句话描述了状态 \(s\) 的（    ）；“在状态 \(s\) 按照某个策略采取动作 \(a\) 后在未来所获得回报值的期望”这句话描述了状态 \(s\) 的（    ）。**  
**选项**：  
A. 策略优化  
B. 价值函数  
C. 动作－价值函数  
D. 采样函数  

**答案**：**B**（第一空），**C**（第二空）  
**解析**：  
- **价值函数 \(V^\pi(s)\)**：状态 \(s\) 下遵循策略 \(pi\) 的期望回报。  
- **动作-价值函数 \(Q^pi(s,a)\)**：状态 \(s\) 下执行动作 \(a\) 并遵循策略 \(pi\) 的期望回报。  

## 题目6 
**基于贝尔曼方程的价值函数计算**

**题目描述**：  
将机器人寻路问题简化为一个2×2的网格环境，状态和移动规则如下：  

- **状态空间**：`s₁`, `s₂`, `s₃`, `s₄`（目标状态）, `s_d`（危险终止状态）  
- **移动规则**：  
  - 机器人每次只能向上(U)或向右（R）移动一格。  
  - 从 `s₁` 可移动到 `s₂`（右）或 `s₃`（上）。  
  - 从 `s₂` 可移动到 `s₄`（上）或越界到 `s_d`（右）。  
  - 从 `s₃` 可移动到 `s₄`（右）或越界到 `s_d`（上）。  
- **奖励函数**：  
  - 到达 `s₄`：奖励 `+1`，游戏终止。  
  - 越界到 `s_d`：惩罚 `-1`，游戏终止。  
  - 其他移动：奖励 `0`。  
- **折扣因子**：`γ = 0.99`  
- **初始策略**：`π(s₁) = π(s₂) = π(s₃) = 上（U）`  
- **终止状态价值**：`V(s₄) = V(s_d) = 0`  

**要求**：  
通过联立贝尔曼方程，计算非终止状态 `s₁`, `s₂`, `s₃` 的价值函数。
