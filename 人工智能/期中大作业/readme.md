1.报告内容
任选其一，与人工智能相关，具体可见，但不限于下面所列的条目：
  - (1) 根据课程所学内容，选择自己感兴趣的某个知识点，查阅文献展开探讨，并给出其应用领域
  - (2) 人工智能某一相关技术的研究前沿及发展趋势调研
  - (3) 关于当前某一领域、应用场景中的人工智能应用调研
  - (4) 某一软硬件产品的个人设想，需要结合人工智能某一相关技术，要求人工智能技术的应用合情合理
2.报告撰写要求
题目自拟，字数不少于 3500 字；参考文献不少于 10 篇；要求将问题描述清楚，有头有尾，逻辑连贯清晰；可以查阅资料和文献，但不能抄袭，如有抄袭成绩记为 0 分。
3.评分标准
  - (1)格式工整，语言流畅，逻辑连贯，可读性高，可获得 60%～80%分数。
  - (2)亮点突出，能体现自己的思考过程可获得另外的 20%。
  - (3)请准时交作业，否则将酌情扣分。
4.提交日期
截止时间：5 月 4 日
报告格式要求：具体参见同济大学毕业设计模板（理工类）
例：正文宋体（英文-Times New Roman）；正文宋体五号行距 18 磅等。
