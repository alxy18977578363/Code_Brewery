# 项目目标

使用 FreeAiOps 构建一个智能运维 Agent。

## 核心功能

1. 读取 CPU、内存、错误数量等指标。
2. 读取系统日志。
3. 判断系统是否异常。
4. 分析可能原因。
5. 给出修复建议。
6. 统计检测准确率和平均响应时间。

## 技术选型

- 框架：FreeAiOps
- 部署：Docker Compose
- 语言：Python
- 模型：deepseek 兼容 API
- 测试：至少 20 个测试案例

## 不做的事情

- 不自动执行危险修复命令。
- 不搭建复杂 Kubernetes 集群。
- 不修改生产服务器。
- 不训练大语言模型。
