# 本地 AIOps 可视化网页

## 作用

`web/` 是一个不依赖前端框架的本地控制台原型，采用浅灰背景、白色卡片、左侧导航和蓝色数据图表的后台管理风格。页面只展示项目已经生成的数据和已经实现的操作，不伪造主机、流量等指标。它直接读取：

- `eval/metrics.json`：准确率和 T4/T5 性能统计。
- `eval/results.json`：T4 异常检测结果和证据。
- `eval/t5_results.json`：T5 根因和排查建议。

网页读取离线评估数据，并可通过 T8 API 提交一次观测进行分析。网页不读取 API Key，不修改 FreeAiOps，也不执行修复命令。

## T11 实时控制台

实时区域读取 `/api/results` 和 `/api/freeaiops/status`，展示最近一次真实本机采集的指标、分析结论、FreeAiOps 状态和历史记录。离线评估区域继续读取 `eval/*.json`，保留 20 个案例、准确率和耗时作为课程设计证据。

页面分为四个视图：

- **实时监控**：当前 CPU、内存、磁盘、日志、资源趋势和最新异常。
- **故障检测**：独立入口直接定位到指标输入和结构化故障检测报告表单。
- **历史分析**：最近自动/手动检测记录，点击记录查看完整证据。
- **测试案例**：20 个离线案例和 T7 评估指标，与本机实时数据分开。
- **系统状态**：FreeAiOps 健康检查和项目安全边界。
- **AI 助手**：输入运维问题，服务端调用已配置的兼容模型；可滚动选择某一次历史分析作为上下文，支持常用问题示例、Markdown 回答、复制回答和清空对话。

实时监控默认打开自动检测，可通过开关、暂停按钮和频率选择控制；页面不可见时自动暂停轮询。

实时采集和手动分析是两条独立链路。自动采集只更新实时监控、趋势和历史记录，不会覆盖手动分析表单或其结果；手动分析结果只在点击“分析当前输入”后更新。

手动故障检测中的“填入随机异常案例”不是固定数据：每次点击都会随机生成一组大部分正常、至少一项超阈值的指标，随后点击“生成故障检测报告”即可验证异常检测。该操作调用 `/api/fault-detection`，返回结构化报告并保存历史记录。

历史分析记录和测试案例均可点击查看记录名片。名片按指标展示实际值和阈值：红色表示超过阈值，绿色表示阈值内，灰色表示缺失；同时显示服务、采集时间、异常信号和日志数量。点击遮罩、关闭按钮或按 `Esc` 可关闭名片。

页面打开后会自动执行一次本机采集和 T4/T5 分析，之后每 1 秒自动更新一次；自动采集不依赖评估数据加载，并通过脚本版本号避免浏览器缓存旧逻辑。也可以点击“采集本机数据”立即再次执行。采集由服务端完成，浏览器不会访问用户目录，也不会触发自动修复。页面刷新后，最近结果从 SQLite 恢复。高频模式会快速增加历史记录，长时间运行时应考虑增加保留策略。

当 API 未启动时，实时区域显示不可用提示；当 FreeAiOps 未启动时显示离线，但本地分析仍会完成。

AI 助手不会在浏览器保存或显示 API Key。未配置模型时会返回明确的“尚未配置模型接口”提示；模型回答只作为解释和排查参考，自动修复始终禁止。

## 启动

只需要启动一次本地服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_api.ps1
```

浏览器打开：

```text
http://127.0.0.1:8000/
```

该服务同时提供网页、离线评估数据和分析 API。不要直接双击 `web/index.html`，因为浏览器的 `file://` 安全策略可能阻止读取 `eval/` 下的 JSON 文件。

## 页面功能

- 实时分析：填写指标和可选日志，点击一次“开始分析”即可完成提交、T4/T5 分析并显示结果；不需要手动处理 observation_id。
- 顶部统计：检测准确率、案例数量、异常数量、T4/T5 平均耗时。
- 案例列表：按全部、异常、正常筛选，点击案例查看详情。
- 案例详情：查看异常指标、WARN/ERROR 日志、根因和 AI 建议。
- 指标趋势：展示响应时间折线趋势。
- AI 接入状态：展示模型调用、规则回退和自动修复开关。

当前可交互的功能包括：实时分析、案例筛选、案例详情切换、刷新数据和左侧页面锚点导航。日期选择、主机管理、服务管理等尚未实现的功能没有放入页面。

`scripts/serve_web.ps1` 仍可用于只调试静态网页，但正常使用不再需要它。

## 更新数据

重新运行 T4/T5/T7 命令生成 JSON 后，点击页面右上角“刷新数据”即可。
