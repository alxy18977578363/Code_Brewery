# AI 工作规则
给指挥的ai的标准工作流程

1. 开始工作前必须阅读 PROJECT_SPEC.md、TASKS.md、TEST_PLAN.md。
2. 一次只处理一个任务。
3. 修改前先说明准备修改哪些文件。
4. 不得删除用户已有文件。
5. 不得把 API 密钥写入代码或提交到 Git。
6. 不得执行危险的服务器修改命令。
7. 每次修改后必须运行相关测试。
8. 测试失败时必须说明原因，不得假装成功。
9. 完成任务后更新 TASKS.md 和 CHANGELOG.md。
10. 最后必须报告：
   - 修改了什么
   - 测试了什么
   - 测试结果
   - 未解决的问题
   - 下一步建议
11. 如果我说了一句“今天结束”，请在memory.md里面查看前面做的事情，然后写下今天做的事情，不用很详细也不要太简陋，需要下次再回头看时理解前面的工作，不会忘记后一天的工作
