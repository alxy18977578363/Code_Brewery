# 项目流程图说明

以下对流程图中的每个节点做简要说明：

- 项目启动：明确目标、范围与关键利益方（城市管理、商业运营、研究团队）。
- 确定业务目标：界定夜间经济需要关注的指标，例如人流热度、消费活力、出行流向与业态结构。
- 数据采集：包括真实数据源（点评、POI、出租车轨迹等）和合成增强数据（在隐私与成本限制下，用合成数据补充样本覆盖）。
- 数据清洗与标准化：去重、填充缺失、剔除异常并转换为统一 schema 与时间窗口。
- 时空栅格化与索引：将地理空间映射到栅格或地理单元，便于聚合与可视化。
- 指标计算与建模：计算热力、OD 流量、活力指数，并做基础聚类或评分模型。
- 数据存储（分层）：原始层、清洗层、分析层、展示层，保证可追溯和复用。
- 可视化设计与开发：时空热力、流动路径、业态结构图、趋势图等可视化组件。
- HTML 仪表盘与报告页：将可视化组件组合成交互仪表盘与讲故事式报告页。
- 运营展示与决策支持：输出报告与定期监控，支持城市管理与商业决策。
- 反馈与模型迭代：基于业务反馈与新增数据，持续迭代合成策略与模型参数。

## 使用说明
- 文件 `项目流程图.mmd` 是 Mermaid 格式，可复制到支持 Mermaid 的编辑器（如 VS Code 的 Mermaid 插件、Obsidian、Mermaid Live Editor）直接渲染。
- 如需 PNG/SVG 输出，可在 Mermaid Live Editor 中导出或使用 CI 渲染脚本批量生成。
