# 展示（可视化与 HTML 大屏）

## 展示目标
- 用可视化将复杂时空数据转化为易读的“城市故事”：夜间热点、出行路径与业态分布
- 支持交互筛选（按时间、区域、业态），并能导出图表/数据用于报告

## 可视化组件清单
- KPI 卡片：夜间活力总分、当日热点网格数、活跃商户数、夜间总客流
- 时空热力图：基于 `grid_id` 的夜间活力热力渲染（支持时间滑块）
- 流向弧线图（Chord/流线）：显示夜间主客流 OD 路径，可按时间段聚合
- 业态结构图：饼图/条形图显示商圈内不同业态占比
- 趋势图：时间序列显示活力指数或客流随时间变化
- 异常提示卡：展示告警记录与可能原因

## 前端实现细节
- 技术栈：纯静态 HTML + JavaScript（现有 `dashboard/`），或使用轻量框架（Vue/React）增强交互
- 可视化库：D3.js / ECharts / Leaflet（热力与地图渲染）
- 数据加载：展示层 JSON 或通过轻量 API（Flask）按需请求
- 性能优化：对前端使用按需加载、图层级别简化（聚合到显示分辨率）与缓存

## HTML 大屏结构（示例）
- 页面 header（项目名、更新时间）
- 左上：KPI 卡片
- 中央：地图 + 时间滑块（热力图 + 流向图切换）
- 右侧：业态占比与 Top N 排行
- 底部：时间序列与自动生成的洞察说明

## 可访问性与导出
- 支持 PNG 导出图表与 CSV 导出明细
- 提供打印友好视图（用于 PPT 生成）

## 部署与运维
- 静态前端可放在任意静态主机（Nginx / GitHub Pages），若需要动态接口则部署 Flask 服务并使用反向代理
- 定期生成 `dashboard_payload.json` 并部署到 CDN 或 S3，以减少实时 DB 负载

## 进一步增强建议
- 加入用户权限与角色（城市管理与商业团队视图差异）
- 支持事件叠加（节假日、临时演出）与对比分析
- 将可视化组件封装为独立微前端组件，便于组合成不同报告页
