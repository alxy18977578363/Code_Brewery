# 项目流程图（详细）说明

本流程图按你描述的实际流程整理，包含两条主要数据来源路径（Kaggle 数据集 + Meituan/大众点评爬取），以及后续的数据集成、存储、建模与可视化环节。

节点说明：

- 项目启动：明确目标、数据权限与时间范围，确认指标与利益相关方。
- Part 1: Kaggle 数据集采集：检索并下载开源数据集（如 POI、评论、出租车轨迹、人口/栅格数据），用于初期样本与基线分析。
- Part 2: 爬取 Meituan / 大众点评：编写爬虫脚本（`scripts/crawl_dianping_poi` 等），获取商户信息、评分、评论、类目等，在遵守法律与服务条款前提下进行采集。
  - 反爬策略：IP 池、速率限制、请求头与模拟浏览器等，必要时做匿名代理与重试机制。
- 数据集成与 ETL：对来自 Kaggle 与爬虫的数据做字段映射、格式对齐、ID 归一化，合并到统一 schema。
- 数据清洗与标准化：去重、缺失值填充、异常值处理、时间戳统一到夜间窗口（例如 18:00-04:00）。
- 时空栅格化 / 经纬度映射：将经纬度映射到城市栅格或行政单元（如街区、商圈），便于聚合分析与可视化。
- 数据存储：使用 `MySQL` 作为主存储，按层设计：原始表、清洗表、聚合表；对大表采用分表或分库策略，并为展示提供轻量化汇总表或导出 JSON。
- 指标建模与特征工程：构造夜间活力指数、客流 OD 矩阵、业态聚合指标（餐饮、娱乐、住宿等），并计算趋势与环比。
- 统计分析与模型验证：用统计检验（t 检验、显著性检验）、相关性分析或简单回归验证指标稳定性与业务相关性。
- 可视化设计与开发：设计时空热力图、流向弧线图、业态结构饼图、KPI 卡片与时间序列图，前端使用 HTML + JavaScript（或现成可视化库）渲染。
- 可视化大屏 / HTML 报告：将可视化组件组合为仪表盘与讲故事式报告页，支持交互筛选与导出。
- 部署与运营：配置定时任务（cron / Windows Task Scheduler）定期执行爬取与 ETL，建立监控与告警，基于业务反馈进行模型与采集策略迭代。

输出与交付物建议：

- 数据：MySQL 数据库里按层组织的表 + 定期导出的展示级 JSON/CSV。
- 代码：爬虫脚本、ETL 脚本、指标计算脚本、可视化前端文件（`dashboard/` 下已有示例）。
- 文档：数据字典、采集合规说明、运行手册、可视化交互说明。
