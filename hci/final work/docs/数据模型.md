# Chennai Restaurant Dataset - 数据模型设计文档

## 一、数据模型概览

### 1.1 模型架构

本数据模型采用**星型模型**(Star Schema)设计，包含1个中心事实表和5个维度表，支持多维度分析。

```
                    ┌──────────────────┐
                    │   rating_segment  │ (维度)
                    │   (评分分段)       │
                    └────────┬──────────┘
                             │
                    ┌────────▼──────────┐
                    │   restaurant       │ (事实表)
                    │   (餐厅主表)       │
                    └────────┬──────────┘
                   ┌─────────┼─────────┐
                   │         │         │
        ┌──────────▼─┐  ┌───▼────────┐ ┌──────────────┐
        │    area     │  │  cuisine   │ │restaurant_   │
        │  (地区维表) │  │(菜系维表)  │ │features      │
        └────────────┘  │            │ │(特色维表)    │
                        └─┬──────────┘ └──────────────┘
                          │
                    ┌─────▼──────────┐
                    │restaurant_     │
                    │cuisine (中间表)│
                    └────────────────┘
```

### 1.2 模型统计

| 表类型 | 表名 | 行数预估 | 字段数 | 用途 |
|-------|------|--------|-------|------|
| 事实表 | restaurant | 11,847 | 12 | 餐厅核心信息 |
| 维表 | area | 150+ | 7 | 地理维度 |
| 维表 | cuisine | 50+ | 5 | 菜系维度 |
| 维表 | rating_segment | 5 | 6 | 评分等级维度 |
| 扩展表 | restaurant_features | 11,847 | 11 | 服务特色 |
| 中间表 | restaurant_cuisine | ~25,000 | 2 | 多对多关系 |

## 二、详细表设计

### 2.1 事实表: restaurant (餐厅主表)

#### 表定义

```sql
CREATE TABLE restaurant (
    -- 主键
    restaurant_id INT PRIMARY KEY AUTO_INCREMENT COMMENT '餐厅唯一标识',
    
    -- 基础属性
    name VARCHAR(255) NOT NULL UNIQUE COMMENT '餐厅名称',
    segment_type VARCHAR(50) NOT NULL COMMENT '业态类型',
    
    -- 地理属性
    area_id INT COMMENT '所属地区ID',
    latitude DECIMAL(10,8) COMMENT '纬度',
    longitude DECIMAL(11,8) COMMENT '经度',
    
    -- 评分属性
    avg_rating DECIMAL(3,2) COMMENT '平均评分 (0.0-5.0)',
    rating_count INT DEFAULT 0 COMMENT '评分总数',
    review_count INT DEFAULT 0 COMMENT '评论数',
    
    -- 质量属性
    rating_band VARCHAR(50) COMMENT '评分等级',
    quality_score DECIMAL(5,2) COMMENT '综合质量分 (0-100)',
    
    -- 统计属性
    restaurant_count INT COMMENT '所属分类的总餐厅数',
    
    -- 时间属性
    created_date DATE DEFAULT CURDATE() COMMENT '创建日期',
    updated_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    -- 索引
    FOREIGN KEY (area_id) REFERENCES area(area_id),
    INDEX idx_segment (segment_type),
    INDEX idx_rating (avg_rating),
    INDEX idx_area (area_id),
    INDEX idx_band (rating_band),
    INDEX idx_created (created_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='餐厅主表 - 事实表';
```

#### 字段说明

| 字段名 | 数据类型 | 可空 | 说明 | 示例 |
|-------|--------|------|------|------|
| restaurant_id | INT | N | 主键自增 | 1001 |
| name | VARCHAR(255) | N | 餐厅唯一名称 | Taj Exotica |
| segment_type | VARCHAR(50) | N | 业态类型 | Restaurant / Fast Food |
| area_id | INT | Y | 地区外键 | 5 |
| latitude | DECIMAL(10,8) | Y | 纬度坐标 | 12.9675 |
| longitude | DECIMAL(11,8) | Y | 经度坐标 | 80.1491 |
| avg_rating | DECIMAL(3,2) | Y | 平均评分 | 3.85 |
| rating_count | INT | Y | 评分数量 | 1250 |
| review_count | INT | Y | 评论数 | 385 |
| rating_band | VARCHAR(50) | Y | 评分等级 | Excellent/Very Good |
| quality_score | DECIMAL(5,2) | Y | 综合质量分 | 78.50 |
| restaurant_count | INT | Y | 类别总数 | 5292 |

#### 数据质量规则

```sql
-- 1. 评分范围检查
ALTER TABLE restaurant ADD CONSTRAINT chk_rating 
    CHECK (avg_rating >= 0 AND avg_rating <= 5.0);

-- 2. 坐标范围检查 (Chennai地理边界)
ALTER TABLE restaurant ADD CONSTRAINT chk_coords
    CHECK (latitude BETWEEN 12.8 AND 13.2 
           AND longitude BETWEEN 79.9 AND 80.3);

-- 3. 时间顺序检查
ALTER TABLE restaurant ADD CONSTRAINT chk_date_order
    CHECK (created_date <= updated_date);
```

### 2.2 维度表: area (地区维表)

#### 表定义

```sql
CREATE TABLE area (
    -- 主键
    area_id INT PRIMARY KEY AUTO_INCREMENT COMMENT '地区唯一标识',
    
    -- 地区信息
    area_name VARCHAR(100) NOT NULL UNIQUE COMMENT '地区名称',
    area_type VARCHAR(50) COMMENT '地区类型 (Commercial/Residential/Mixed)',
    
    -- 地理信息
    latitude_center DECIMAL(10,8) COMMENT '地区中心纬度',
    longitude_center DECIMAL(11,8) COMMENT '地区中心经度',
    area_size_sqkm DECIMAL(8,2) COMMENT '地区面积(平方公里)',
    
    -- 统计信息
    restaurant_count INT DEFAULT 0 COMMENT '该地区餐厅总数',
    avg_rating DECIMAL(3,2) COMMENT '该地区平均评分',
    high_rated_count INT DEFAULT 0 COMMENT '高评分(>=4.0)餐厅数',
    
    -- 质量评级
    quality_tier VARCHAR(20) COMMENT '质量等级 (Premium/Standard/Developing)',
    saturation_level VARCHAR(20) COMMENT '饱和度等级 (High/Medium/Low)',
    
    -- 时间属性
    created_date DATE DEFAULT CURDATE(),
    updated_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    -- 索引
    INDEX idx_name (area_name),
    INDEX idx_type (area_type),
    INDEX idx_quality (quality_tier),
    INDEX idx_rating (avg_rating)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='地区维度表';
```

### 2.5 扩展表: restaurant_features (餐厅特色服务表)

#### 表定义

```sql
CREATE TABLE restaurant_features (
    -- 主键
    feature_id INT PRIMARY KEY AUTO_INCREMENT COMMENT '特色ID',
    
    -- 外键
    restaurant_id INT NOT NULL UNIQUE COMMENT '餐厅ID',
    
    -- 服务特色 (布尔值)
    has_home_delivery BOOLEAN DEFAULT FALSE COMMENT '提供外卖',
    has_dine_in BOOLEAN DEFAULT FALSE COMMENT '堂食就餐',
    has_breakfast BOOLEAN DEFAULT FALSE COMMENT '提供早餐',
    has_desserts BOOLEAN DEFAULT FALSE COMMENT '甜点烘焙',
    is_vegetarian_only BOOLEAN DEFAULT FALSE COMMENT '纯素食',
    has_outdoor_seating BOOLEAN DEFAULT FALSE COMMENT '户外座位',
    has_free_parking BOOLEAN DEFAULT FALSE COMMENT '免费停车',
    has_wifi BOOLEAN DEFAULT FALSE COMMENT '无线网络',
    has_table_booking BOOLEAN DEFAULT FALSE COMMENT '支持订位',
    is_delivery_only BOOLEAN DEFAULT FALSE COMMENT '只提供外卖',
    
    -- 聚合字段
    feature_count INT GENERATED ALWAYS AS (
        has_home_delivery + has_dine_in + has_breakfast + 
        has_desserts + is_vegetarian_only + has_outdoor_seating + 
        has_free_parking + has_wifi + has_table_booking
    ) STORED COMMENT '特色服务总数',
    
    -- 时间属性
    created_date DATE DEFAULT CURDATE(),
    updated_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    -- 外键和索引
    FOREIGN KEY (restaurant_id) REFERENCES restaurant(restaurant_id),
    INDEX idx_restaurant (restaurant_id),
    INDEX idx_delivery (has_home_delivery),
    INDEX idx_breakfast (has_breakfast),
    INDEX idx_feature_count (feature_count)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='餐厅特色服务表';
```

### 2.6 中间表: restaurant_cuisine (多对多关系表)

#### 表定义

```sql
CREATE TABLE restaurant_cuisine (
    -- 联合主键
    restaurant_id INT NOT NULL COMMENT '餐厅ID',
    cuisine_id INT NOT NULL COMMENT '菜系ID',
    
    -- 关系描述
    is_primary BOOLEAN DEFAULT FALSE COMMENT '是否为主菜系',
    cuisine_order INT COMMENT '菜系排序 (1=主菜系)',
    
    -- 时间属性
    created_date DATE DEFAULT CURDATE(),
    
    -- 主键和外键

    FOREIGN KEY (restaurant_id) REFERENCES restaurant(restaurant_id) ON DELETE CASCADE,
    FOREIGN KEY (cuisine_id) REFERENCES cuisine(cuisine_id),
    
    -- 索引
    INDEX idx_cuisine (cuisine_id),
    INDEX idx_primary (is_primary)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='餐厅与菜系的多对多关系表';
```

## 三、关键分析视图

### 3.1 地区概览视图

```sql
CREATE VIEW vw_area_overview AS
SELECT 
    a.area_id,
    a.area_name,
    a.quality_tier,
    a.saturation_level,
    COUNT(r.restaurant_id) as total_restaurants,
    AVG(r.avg_rating) as avg_rating,
    SUM(CASE WHEN r.avg_rating >= 4.0 THEN 1 ELSE 0 END) as high_rated_count,
    SUM(CASE WHEN r.avg_rating < 3.0 THEN 1 ELSE 0 END) as below_avg_count,
    a.latitude_center,
    a.longitude_center
FROM area a
LEFT JOIN restaurant r ON a.area_id = r.area_id
GROUP BY a.area_id
ORDER BY total_restaurants DESC;
```

### 3.2 菜系分析视图

```sql
CREATE VIEW vw_cuisine_analysis AS
SELECT 
    c.cuisine_id,
    c.cuisine_name,
    c.cuisine_category,
    COUNT(DISTINCT rc.restaurant_id) as restaurant_count,
    AVG(r.avg_rating) as avg_rating,
    MIN(r.avg_rating) as min_rating,
    MAX(r.avg_rating) as max_rating,
    STDDEV(r.avg_rating) as rating_stddev,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM restaurant), 2) as market_share_percent
FROM cuisine c
LEFT JOIN restaurant_cuisine rc ON c.cuisine_id = rc.cuisine_id
LEFT JOIN restaurant r ON rc.restaurant_id = r.restaurant_id
GROUP BY c.cuisine_id
ORDER BY restaurant_count DESC;
```

### 3.3 评分分布视图

```sql
CREATE VIEW vw_rating_distribution AS
SELECT 
    rs.band_id,
    rs.band_name,
    rs.min_rating,
    rs.max_rating,
    COUNT(r.restaurant_id) as restaurant_count,
    ROUND(COUNT(r.restaurant_id) * 100.0 / (SELECT COUNT(*) FROM restaurant), 2) as percentage,
    AVG(r.avg_rating) as avg_rating_in_band,
    GROUP_CONCAT(DISTINCT r.segment_type ORDER BY r.segment_type SEPARATOR ', ') as segments
FROM rating_segment rs
LEFT JOIN restaurant r ON (r.avg_rating >= rs.min_rating AND r.avg_rating <= rs.max_rating)
GROUP BY rs.band_id
ORDER BY rs.band_id;
```

## 四、常用查询

### 4.1 Top 10餐厅查询

```sql
-- 按评分排序的Top 10餐厅
SELECT 
    r.restaurant_id,
    r.name,
    r.avg_rating,
    r.review_count,
    a.area_name,
    r.segment_type,
    GROUP_CONCAT(c.cuisine_name SEPARATOR ', ') as cuisines
FROM restaurant r
LEFT JOIN area a ON r.area_id = a.area_id
LEFT JOIN restaurant_cuisine rc ON r.restaurant_id = rc.restaurant_id
LEFT JOIN cuisine c ON rc.cuisine_id = c.cuisine_id
GROUP BY r.restaurant_id
ORDER BY r.avg_rating DESC, r.review_count DESC
LIMIT 10;
```

### 4.2 地区热力图数据

```sql
-- 生成地区热力地图数据
SELECT 
    a.area_id,
    a.area_name,
    a.latitude_center,
    a.longitude_center,
    COUNT(r.restaurant_id) as restaurant_count,
    AVG(r.avg_rating) as avg_rating,
    a.quality_tier,
    a.saturation_level,
    SUM(CASE WHEN rf.has_home_delivery THEN 1 ELSE 0 END) as delivery_count
FROM area a
LEFT JOIN restaurant r ON a.area_id = r.area_id
LEFT JOIN restaurant_features rf ON r.restaurant_id = rf.restaurant_id
GROUP BY a.area_id
ORDER BY restaurant_count DESC;
```

### 4.3 推荐引擎查询

```sql
-- 基于菜系和地区的推荐
SELECT 
    r.restaurant_id,
    r.name,
    r.avg_rating,
    a.area_name,
    GROUP_CONCAT(c.cuisine_name SEPARATOR ', ') as cuisines,
    rf.feature_count,
    CASE 
        WHEN r.avg_rating >= 4.5 THEN 'Excellent'
        WHEN r.avg_rating >= 4.0 THEN 'Very Good'
        WHEN r.avg_rating >= 3.5 THEN 'Good'
        WHEN r.avg_rating >= 3.0 THEN 'Average'
        ELSE 'Below Average'
    END as quality_band
FROM restaurant r
LEFT JOIN area a ON r.area_id = a.area_id
LEFT JOIN restaurant_cuisine rc ON r.restaurant_id = rc.restaurant_id
LEFT JOIN cuisine c ON rc.cuisine_id = c.cuisine_id
LEFT JOIN restaurant_features rf ON r.restaurant_id = rf.restaurant_id
WHERE a.area_name = 'Porur'  -- 指定地区
  AND c.cuisine_name IN ('Chinese', 'North Indian')  -- 指定菜系
  AND r.avg_rating >= 3.5  -- 最低评分
GROUP BY r.restaurant_id
ORDER BY r.avg_rating DESC
LIMIT 10;
```

## 五、性能优化方案

### 5.1 索引优化

```sql
-- 创建复合索引
CREATE INDEX idx_area_rating ON restaurant(area_id, avg_rating);
CREATE INDEX idx_segment_rating ON restaurant(segment_type, avg_rating);
CREATE INDEX idx_area_segment ON restaurant(area_id, segment_type);

-- 创建全文索引 (用于名称搜索)
ALTER TABLE restaurant ADD FULLTEXT INDEX ft_name (name);

-- 创建分区索引
ALTER TABLE restaurant ADD INDEX idx_created_year 
    ((YEAR(created_date)));
```

### 5.2 查询优化

```sql
-- 使用EXPLAIN分析查询
EXPLAIN SELECT * FROM restaurant WHERE area_id = 5 AND avg_rating >= 3.5;

-- 避免全表扫描，使用覆盖索引
SELECT r.restaurant_id, r.name, r.avg_rating 
FROM restaurant r 
USE INDEX (idx_area_rating)
WHERE r.area_id = 5 AND r.avg_rating >= 3.5;
```

### 5.3 缓存策略

```python
# Python + Redis缓存示例
import redis
import json

cache = redis.Redis(host='localhost', port=6379, db=0)

    if cached:
        return json.loads(cached)
    
    # 从数据库查询
    result = query_database(area_id)
```

## 六、数据维护

### 6.1 ETL维护脚本

```python
# 定期更新统计信息
UPDATE rating_segment rs
SET restaurant_count = (
    SELECT COUNT(*) FROM restaurant r
    WHERE r.avg_rating BETWEEN rs.min_rating AND rs.max_rating
),
percentage = (
    SELECT ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM restaurant), 2)
    FROM restaurant r
    WHERE r.avg_rating BETWEEN rs.min_rating AND rs.max_rating
);

# 更新地区统计
UPDATE area a
SET restaurant_count = (
    SELECT COUNT(*) FROM restaurant r WHERE r.area_id = a.area_id
),
avg_rating = (
    SELECT AVG(avg_rating) FROM restaurant r WHERE r.area_id = a.area_id
);
```

### 6.2 数据质量检查

```sql
-- 检查缺失值
SELECT 
    '餐厅名称' as field, COUNT(*) as missing_count
FROM restaurant WHERE name IS NULL
UNION ALL
SELECT '地区ID', COUNT(*) FROM restaurant WHERE area_id IS NULL
UNION ALL
SELECT '评分', COUNT(*) FROM restaurant WHERE avg_rating IS NULL;

-- 检查重复值
SELECT name, COUNT(*) as count
FROM restaurant
GROUP BY name
HAVING count > 1;

-- 检查业务规则
SELECT COUNT(*) as invalid_ratings
```
