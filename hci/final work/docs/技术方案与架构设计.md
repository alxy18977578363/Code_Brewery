# Chennai Restaurant Dataset - 技术方案与架构设计

## 一、项目概述

### 1.1 项目背景
随着互联网技术的发展，餐饮行业正加速向数字化发展。chennai作为印度大都市之一，人口密集，饮食文化多元。本项目基于Zomato平台数据搭建chennai大数据分析与可视化平台，能够更好地揭示该城市餐饮行业发展特征，提供用户决策、商家运营的数据支撑。

### 1.2 项目目标
- **数据分析**: 挖掘餐厅评分、菜系、地理位置的关联规律
- **可视化展示**: 构建多维度交互式仪表板
- **决策支持**: 为餐厅运营商、投资者、数据分析师提供洞察
- **推荐系统**: 实现基于位置和菜系的餐厅推荐引擎

### 1.3 核心指标
| 指标 | 数值 |
|------|------|
| 总餐厅数 | 11,848家 |
| 平均评分 | 3.52/5.0 |
| 高评分餐厅(≥4.0) | 1,837家(15.5%) |
| 需改进餐厅(<3.0) | 1,291家(10.9%) |
| 覆盖区域 | 150+地区 |

## 六、分析方案设计
### 6.1.1 空间异构性分析
疑惑：钦奈不同区域的餐厅供给和评分是否存在显著空间差异

- 使用列名
- area/location
- latitude
- longitude
- dining_rating
- restaurant_id

探索：
高评分餐厅是否集中在少数区域？
餐厅密集区是否一定评分更高？
不同区域的餐饮生态是否均衡？

适合的表格/图表
1. 地区差异：（地区*评分）
请将area列作为词元图元素，绘制词元图（echarts） 。箱线图
堆叠图（使用评分分级，此次需要补充餐厅总数到各区域的柱顶） 气泡图 x：餐厅数，y：平均评分，气泡代表区域规模-- 这俩放在一行
核密度热力图（一个平均评分，一个区域餐厅总数）

四象限矩阵图（供给 vs 评分）
X 轴：餐厅数量（供给）
Y 轴：平均评分

象限划分：
右上：高供给、高评分（成熟优质餐饮区）
左上：低供给、高评分（小而美 / 潜力区）
右下：高供给、低评分（竞争激烈但质量不稳）
左下：低供给、低评分（待发展区）
