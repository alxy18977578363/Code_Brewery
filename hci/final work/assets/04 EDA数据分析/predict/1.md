### 4.4 机器学习评分预测（Prediction Lab 页面）
- **特征审计**：原始输入特征块（分类 / 数值 / 文本）汇总
- **模型对比**（Leaderboard）：
  - DummyRegressor（基线）→ Ridge → ElasticNet → RandomForest → HistGradientBoosting
  - 可选加入 XGBoost / LightGBM
  - 评价指标：MAE（主要）、RMSE、R²
- **残差分析**：
  - 六边形密度图（Actual vs Predicted），对角线虚线为完美预测参考
  - 残差直方图，正值 = 模型低估
- **误差细分**：按 Market Segment 和 Area 分解 MAE + Bias
- **特征重要性**：
  - Permutation Importance（打乱特征后 MAE 增量）
  - Ridge 系数方向（正向 / 负向关联特征）
- **偏依赖分析（PDP）**：
  - Brand Footprint Curve：同名门店数 → 预测评分
  - Location-Distance Curve：距城市中心距离 → 预测评分
  - Menu-Description Curve：招牌菜 token 数 → 预测评分
  - Segment Partial Dependence：各细分市场的平均预测评分
- **关键发现**：
  - 品牌足迹（同名门店数）是评分最强正向预测因子
  - 距离市中心越远评分倾向越低
  - 招牌菜丰富度对评分有正向贡献
  - Cloud Kitchen / Dine-out 的预测评分最高
