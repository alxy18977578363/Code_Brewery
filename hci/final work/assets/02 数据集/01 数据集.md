### 2.3 核心字段说明
| 字段 | 类型 | 说明 |
|------|------|------|
| `restaurant` | 文本 | 餐厅名称 |
| `rating` | 数值 (0–5) | 目标变量，用户评分 |
| `market_segment` | 分类 | 市场细分（Dine-out / Delivery / Cafes / Bar / Dessert Parlours 等） |
| `area` | 分类 | 所在区域（Porur / Anna Nagar / T. Nagar 等） |
| `cuisine` | 文本 | 菜系类型（Chinese / Indian / Continental 等） |
| `top_dishes` | 文本 | 招牌菜（Filter Coffee / Biryani / Dosa 等） |
| `features` | 文本 | 服务特征（Home Delivery / Indoor Seating / Lunch Buffet 等） |
| `latitude` / `longitude` | 数值 | GPS 坐标，用于空间分析 |
| `address` | 文本 | 详细地址 |

在原始字段基础上派生以下特征：
- **空间偏移**：`lat_offset`、`lon_offset`（相对城市中心的偏移）
- **距离特征**：`distance_to_city_median_km`（到城市中位坐标距离）
- **品牌足迹**：`same_name_outlets`（同名门店数）、`is_multi_outlet_name`（是否连锁）
- **文本向量化**：cuisine / features / top_dishes 分别使用 CountVectorizer / TfidfVectorizer
- **分类编码**：market_segment / area 使用 One-Hot 编码
- **评分分段**：`rating_band`（fragile / developing / solid / strong / elite）


### 1.4 长格式数据拆分

原始数据中的 `cuisine`、`features/category`、`top_dishes` 三列都是**逗号分隔的多值文本**，为了支持多维分析，这些字段被展开为三个独立的长格式数据表：

#### 📊 长格式数据概览

| 维度 | 原始表 | 长格式表 | 行数 | 唯一值 | 膨胀倍数 |
|------|---------|---------|------|--------|---------|
| **菜系** | 1列/11,848行 | long_format_cuisine.csv | 28,799 | 92种菜系 | **2.43x** |
| **特色** | 1列/11,848行 | long_format_feature.csv | 32,698 | 78种特色 | **2.76x** |
| **菜品** | 1列/11,848行 | long_format_dish.csv | 76,763 | 2,036种菜品 | **6.48x** |


#### 📁 长格式表结构

所有三个长格式表都保留以下基础列，以支持多维分析：
- `restaurant_id`: 餐厅唯一标识
- `restaurant`: 餐厅名称
- `market_segment`: 市场细分
- `area`: 所属地区
- `rating`: 餐厅评分
- `latitude`, `longitude`: 地理坐标
- `cuisine` / `feature` / `dish`: 展开后的单个属性值

#### 🎯 长格式数据的应用

✅ **菜系分析**: 统计各菜系的受欢迎程度、平均评分、覆盖餐厅数  
✅ **特色采用率**: 按市场细分统计服务特色的采用比例  
✅ **菜品排名**: 识别最受欢迎的菜品及其地理分布  
✅ **交叉分析**: 发现菜系与评分、地区与特色等隐藏关系  
✅ **可视化**: 生成菜系排名图、特色热力图、菜品云图等
