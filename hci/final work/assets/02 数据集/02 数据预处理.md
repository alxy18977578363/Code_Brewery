## 🛠️ 衍生特征工程

添加了 **4 个新衍生列**：

| 列名 | 数据类型 | 说明 | 示例值 |
|------|---------|------|-------|
| restaurant_id | int | 唯一标识符 | 1, 2, 3, ... |
| rating_band | categorical | 评分分段等级 | "fragile", "developing", "solid", "strong", "elite" |
| same_name_outlets | int | 同名出现次数 | 1, 2, 5, 18, ... |
| is_multi_outlet_name | bool | 是否为多出口品牌 | True / False |

**评分分段定义：**
- **fragile**: 评分 < 2.9
- **developing**: 2.9 ≤ 评分 < 3.4
- **solid**: 3.4 ≤ 评分 < 3.8
- **strong**: 3.8 ≤ 评分 < 4.2
- **elite**: 评分 ≥ 4.2
