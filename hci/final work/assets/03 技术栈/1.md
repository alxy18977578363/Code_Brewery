## 第三部分：技术栈

### 3.1 后端框架
- **Flask**：轻量级 Python Web 框架
- **Blueprint 架构**：Blueprint 路由模块，支持多页面扩展
- **分层设计**：Service（业务逻辑）→ Route（路由/接口）→ Template（模板渲染）

### 3.2 数据处理
- **Pandas**：数据加载、清洗、聚合
- **NumPy**：直方图、统计计算
- **SciPy**：核密度估计（KDE）

### 3.3 可视化
- **Plotly.js**：所有交互式图表（散点、柱形、热力图、箱线、小提琴、六边形等）
- **ECharts**：词云图（Area 名称词云）
- **Plotly Mapbox**：地理空间可视化（密度热力图、散点地图）

### 3.4 机器学习
- **scikit-learn**：Ridge / ElasticNet / RandomForest / HistGradientBoosting
- **XGBoost**（可选）、**LightGBM**（可选）
- **Pipeline + ColumnTransformer**：自动化特征工程
- **GroupShuffleSplit**：按餐厅名分组划分，防止数据泄漏
- **Permutation Importance / PDP / Ridge 系数**：模型可解释性分析

### 3.5 前端技术
- 原生 **JavaScript**（无框架依赖）
- **CSS** 主题
