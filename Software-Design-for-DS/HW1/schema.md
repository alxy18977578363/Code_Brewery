# OK-VQA 数据集 schema 说明文档

本说明文档详细描述 OK-VQA 主表及联合索引表的各字段含义、类型及设计原则，便于后续数据处理、分析与质量验证。

---

## 1. 主表（okvqa_main）字段说明

| 字段名        | 类型     | 含义                           |
|---------------|----------|--------------------------------|
| question_id   | int      | 问题唯一标识，主键。每条问答数据的唯一ID。|
| image_id      | int/str  | 图片唯一标识。建议为图片文件名、路径或哈希值。|
| question      | string   | 问题文本。自然语言描述的问题内容。|
| question_type | string   | 问题类型。对问题内容的分类标签，如“植物与动物”、“交通工具”等。|
| answer_type   | string   | 答案类型。对答案的高层次分类，如“other”、“number”等。|


---

## 2. 联合索引表（okvqa_qtype_atype_index）字段说明

| 字段名         | 类型     | 含义                           |
|----------------|----------|--------------------------------|
| question_type  | string   | 问题类型。与主表一致。         |
| answer_type    | string   | 答案类型。与主表一致。         |
| question_id    | int      | 关联主表的唯一ID。             |

该表用于支持基于 question_type + answer_type 的高效分组检索与统计分析。

---

## 3. 设计原则与说明

- **唯一性**：question_id 为主键，保证每条数据唯一。
- **可扩展性**：如需支持多答案，可单独建立答案索引表（answer_index），实现一对多结构。
- **图片字段**：主表仅存 image_id，图片内容建议单独存储。
- **类型一致性**：所有字段类型需与实际数据严格对应，避免类型不一致导致的数据质量问题。
