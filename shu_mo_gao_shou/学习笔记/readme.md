# numpy 和 pandas  
## 2025.4.20

| 分类       | 功能/方法                  | 说明或示例                                 |
|------------|----------------------------|--------------------------------------------|
| 导入库     | `import numpy as np`       | 导入 NumPy 并简写为 `np`                   |
| 创建数组   | `np.array([1, 2, 3])`      | 创建一维数组                               |
|            | `np.empty((2,3))`          | 生成一个 2×3 的所有值靠近0的矩阵           |
|            | `np.zeros((2,3))`          | 创建全0二维数组，括号内是矩阵的形状        |
|            | `np.ones((3,3))`           | 创建全1数组，括号内是矩阵的形状            |
|            | `np.arange(0,10,2)`        | 类似于 Python 的 `range()` 函数           |
|            | `np.linspace(0,1,5)`       | 将一段长度平分成多份（包括首尾）           |
| 数组属性   | `.shape`                   | 查看数组维度（行，列）                     |
|            | `.dtype`                   | 数据类型，如 `int32`, `float64` 等         |
|            | `.ndim`                    | 数组维度数量                               |
|            | `.size`                    | 数组元素总数                               |
| 修改结构   | `arr.reshape(2, 3)`        | 改变数组形状，变成 2×3 的二维矩阵          |
|            | `arr.T`                    | 矩阵转置（行列互换）                       |
| 基础运算   | `>`,`==`,`<`               | 例如array < 3 就是逐个元素和其比较，返回一个array，含False，True|
|            | `+`,`-`                    | 若给的是元素，则整体增加，若给的是矩阵，则对位相加 |
|            | `*`,`np.dot(a,b)`,`a.dot(b)`| 直接a*b表示对位点乘，np.dot则表示矩阵乘法   | 
|            |`np.argmin()`,`a.argmax()`| 得到最小、最大值的下标，是**展平后的索引**    |
|            |`np.mean()`,`np.average()`   |     求平均值                              |
|            |`np.median()`                |           **展平**求中位数                |
|            |`np.cumsum()`                | **展平**求前n项的前缀和                   |
|            |`np.diff()`                | **展平**求差分                             |
